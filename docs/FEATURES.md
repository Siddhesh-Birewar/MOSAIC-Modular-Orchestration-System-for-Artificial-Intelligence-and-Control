# Planned features

The full product is a local-first personal assistant. Planned capabilities include local AI conversation and model switching; English, Hindi and Hinglish voice; chat history and personal memory; notes, notebooks and learning workspaces; progress, doubts, revision schedules and quizzes; document knowledge base and RAG with OCR; multiple independent software projects and GitHub context; permissioned macOS app/file automation; Apple Music; reminders, scheduling and daily briefings; native plugins and MCP servers; and a desktop dashboard for customization, permissions, and plugin management.

These are roadmap scope, not claims of current implementation. Phase 1 includes only backend health, Ollama model listing, and basic single-request chat.
