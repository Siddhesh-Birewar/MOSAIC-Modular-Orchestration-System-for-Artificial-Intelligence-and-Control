# Roadmap

1. Project foundation — 5% (complete): repository, backend skeleton, local runtime check, baseline docs.
2. Intelligence engine — 12% (complete): model routing and conversation behavior.
3. Safe tool execution — 20% (in progress): validated tools, interactive CLI, and user approval boundaries.
4. Persistent memory, notes and learning — 30%: local SQLite-backed user data.
5. Desktop dashboard MVP — 40%: settings, permissions, plugins and chat UI.
6. Natural voice assistant — 50%: local multilingual speech recognition and synthesis.
7. Knowledge base and RAG — 60%: local document ingestion, OCR and retrieval.
8. Project intelligence — 70%: isolated development project context and GitHub integration.
9. Plugin ecosystem — 80%: documented native and MCP extension interfaces.
10. Personal integrations and automation — 88%: reminders, calendar, music and briefings.
11. Advanced intelligence and optimization — 95%: model selection and resource tuning.
12. Production readiness — 100%: packaging, reliability, security and release checks.
